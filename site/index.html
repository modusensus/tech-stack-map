AI · 数学

两个向量的「点积」怎么算？几何意义是什么？

对应分量相乘再求和：a·b = a₁b₁ + a₂b₂ + …。几何上等于 |a|·|b|·cosθ，衡量两个方向的相似程度。你的记忆门控用的就是它。

AI · 机器学习

「参数」和「超参数」有什么区别？

参数是模型自己从数据里学出来的（比如权重）；超参数是人事先设好的（学习率、层数、批次大小），训练不会改它。

AI · Transformer

LoRA 低秩适配是什么？

不重训整个大模型，只训练两个小矩阵（把权重更新拆成低秩的两个小矩阵相乘）来微调。省显存、省时间。

HTML · 音视频

audio 里的 <source> 是干嘛的？为什么不直接写 src？

src 只能给一个文件；<source> 能列一串，让浏览器自己挑能放的格式（如 mp3 / ogg），一个一个试。type 属性帮浏览器提前预判格式。

HTML · 表单

placeholder 和 value 的区别？

placeholder 是贴在框里的便签，一撕就没、不会提交；value 是已经写好的字，会跟着表单一起寄出去。

HTML · 标签数量

<main> 和 <header> 各有几个？

<main> 全页唯一，一个页面只能有一个；<header> 可以有多个（页面顶部一个，每篇 article 顶部还能各来一个）。

HTML · 安全

target="_blank" 后面为什么要加 rel="noopener"？

不加的话，新打开的页面能通过 window.opener 反过来操纵你的原页面（那条"隐形电话线"）。noopener 把线剪断。现代 Chrome 88+ 已默认帮你剪，但写上更保险。
