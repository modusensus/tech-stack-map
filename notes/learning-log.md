### 复习巩固（以问答 + 实战方式）

今天没有学新内容，重点是把已学知识通过"问答 + 写代码"的方式彻底巩固。

#### 复习板块

- **`==` vs `is`**：`==` 比较值（内容），`is` 比较身份（内存地址 / id）；`a = [1,2,3]`、`b = [1,2,3]` 时 `a == b` 为 True 但 `a is b` 为 False
- **变量赋值 `=` vs `copy()`**：`b = a` 只是"多配一把钥匙"（同一栋房），改 b 会影响 a；`b = a.copy()` 才是"复制一栋独立房"
- **`while` 条件 + `break` 顺序陷阱**：`while counts > 0` 的含义是"只要 counts 大于 0 就继续"；`break` 只能拦下"它之后还没执行的代码"，拦不住"它之前已经执行的代码"——代码顺序一变结果就变
- **`for` 遍历**：`in` 后面放什么就一个一个拆什么——列表拿元素、字符串拿字符、`range` 拿编号
- **`range(n)`**：从 0 数到 n-1，共 n 个数；`range(1, 11)` 可以指定从 1 开始数到 10
- **`continue`**：跳过本次循环，进入下一次（和 `break` 的"全停"对比记忆）
- **黄金组合**：`for i in range(n)` + `列表[i]` = 按编号逐个取列表元素（`enumerate` 的底层原理）

#### 新学知识点

- **`%` 取余数**：`7 % 3 = 1`；`i % 2 == 0` 判断偶数，`i % 3 == 0` 判断 3 的倍数
- **`!=` 不等于**：和 `==` 相反，`i != 0` 就是"i 不等于 0"
- **`and` 并且**：两边条件都成立才算真，如 `i != 0 and i % 2 == 0`
- **"过滤"思维**：方案 A 从源头避免（改 range 起始），方案 B 放进来再过滤（加条件排除）——数据分析里常用

#### 函数（第一讲）

- **函数 = 把重复动作打包成"菜谱"**，用的时候照菜谱做，不用重复写步骤

- 关键规则：先定义后调用；程序从上往下顺序执行，遇到函数就"钻进菜谱执行一遍再出来"
- 函数价值 = 避免重复
- 参数 = 往菜谱里塞"食材"，同一个菜谱做不同味道

#### 数字类型 & 浮点数

- 浮点数 = 带小数点的数（int 没小数点，float 有小数点）
- **大坑**：`0.1 + 0.2` = `0.30000000000000004`，不是 0.3！因为二进制存不精确
- 实测 `0.3 < 0.1 + 0.2` 是 True
- 别用浮点数直接比相等；算钱用 Decimal；打印好看用 `round()`
- **Decimal** = 精确小数（算钱专用），要用字符串创建 `Decimal("0.1")`，传数字会带进误差
- 自己探索出两种写法：`import decimal` + `decimal.Decimal(...)` 和 `from decimal import Decimal`

#### 进制（计算机基础知识）

- 不同进制 = 不同的数数规则，区别在"满几进一"
- 电脑用二进制（0 和 1），因为电路只有通/断两个状态
- 自己推出了三进制（满3进一）、八进制（满8进一）的规律！

#### import 与模块思维

- **模块思维口诀**：搬箱子（import）→ 拿工具（模块.工具）→ 干活 → 存结果

### Day 2：数字运算 + 函数加工厂思维

#### 数字运算

- **算术运算符**：`+` `-` `*` `/` `//` `%` `**`，重点区分 `/`（结果一定浮点）和 `//`（地板除）
- **比较运算**：`==` `!=` `>` `<` `>=` `<=` 返回 True/False
- **赋值运算**：`+=` `-=` `*=` `/=` 等"偷懒写法"
- **常用数学函数**：`abs()` `round()` `max()` `min()` `sum()` `pow()`
- **math 模块**：`sqrt()` `ceil()` `floor()` `pi` `log()` 等（需要 import）
- **`divmod(x, y)`**：一次性返回 `//` 和 `%` 两个结果 `(商, 余数)`
- **`pow(a, b, c)` 三参数用法**：`pow(2, 3, 4)` = `(2**3) % 4` = 0，适合大数模幂运算

#### 地板除 `//` 与取余 `%`

- `//` = 向下取整（取比真实结果小的最大整数）
- 负数地板除容易踩坑：`-5 // 2 = -3`（不是 -2），因为"向下"是往数轴负方向走
- `%` = 取余数 = "分不完剩下的数"，用分苹果和数手指两个生活例子彻底理解
- 核心公式：`x = (x // y) * y + (x % y)`，商×除数 + 余数 = 被除数

#### 复数进阶

- `abs(复数)` 不是绝对值，而是**模**（到原点的距离），用勾股定理算
- 例：`abs(1+3j)` = √(1²+3²) = √10 ≈ 3.162
- `c.conjugate()` = 共轭复数，虚部符号反过来
- 复数打印带括号 `(1+2j)` 是 Python 官方格式，避免和周围加减号混淆
- **踩坑**：`complex(4, 3+4j)` 输出 `3j`，因为 `complex(real, imag) = real + imag*j`，当 imag 也是复数时会先算 `imag*j`，再用 `j²=-1` 化简

#### 函数 = "输入 → 加工 → 输出"的加工厂

- 顿悟：**函数就是一个黑盒子加工厂**：给输入（参数）→ 机器加工（函数体）→ 拿到输出（return）
- 用榨汁机、咖啡机、你的 `斤转千克` 函数做类比，理解更深刻
- 函数价值：把加工规则封装，避免重复写代码

- 以为 `520.0` 是定点数，其实它就是普通浮点数（Python 没有定点数类型）
- 以为 `abs(1+3j)` 是绝对值，其实复数 abs 算的是"模"（距离）
- `complex(4, 3+4j)` 输出 `3j` 想不通，搞懂后发现是给 imag 位置传了复数导致的

### Docker 学习（并行进行，配合 Linux 云服务器实操）

#### 概念理解

- **Docker = 打包"程序 + 运行环境"**，让"在我电脑能跑"变成"在哪都能跑"
- **镜像（image）= 环境某一瞬间的"快照"**（拍立得比喻：定格/可恢复/可复制）
  - ⚠️ 纠正误区：一开始以为"镜像 = 网络镜像站"，其实是英文 image（图像）和 mirror（镜子/复制品）被中文翻译坑了
- **容器（container）= 用镜像快照"洗"出来的活实例**
- **仓库 / 卷 / 网络**：菜谱图书馆 / 外置硬盘 / 电话线
- **Docker vs 虚拟机**：虚拟机给每个环境装完整系统（几 GB、分钟级），Docker 共享宿主系统只隔离应用（几十 MB、秒级）
- **虚拟机 vs Docker vs AI 沙箱**（三隔离概念）：
  - 虚拟机隔离"整套操作系统"（独立公寓）
  - Docker 隔离"应用+依赖"（共享大楼的住户）
  - AI 沙箱隔离"行为权限"（紧箍咒，越界要用户授权）——TraeCode 里的 trae-sandbox 就是这个

#### 实操（Linux 云服务器）

- **踩坑**：下载了 Docker Desktop（桌面版）装不上，报 `Unsupported file`——因为 Docker Desktop 是给 Windows/Mac 用的，Linux 服务器要用 **Docker Engine**
- 用一键脚本装好了 Docker Engine：`curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh`
- 学会了容器/镜像的完整增删查命令（pull/run/ps/stop/rm/rmi/prune）
- 学会了 `docker logs -f`（看日志）、`docker exec -it bash`（进容器内部）
- 学会了 run 高级参数：`-d`（后台）、`--name`（命名）、`-p`（端口映射）、`-v`（挂载目录，注意必须是 `宿主机路径:容器路径` 两边都要写）
