## Phase 1：数学地基

### 点积 — 量两个方向的相似度

**核心要点**

两个向量**对应位置相乘，再全部加起来**，最后得到**一个数**（不是向量）：

```
a = [1, 2, 3]
b = [4, 5, 6]

点积 = 1×4 + 2×5 + 3×6
     = 4 + 10 + 18
     = 32
```

**趣味类比回顾**

点积在量"两个方向有多像"。

想象你和朋友给三部电影打分：

```
你   = [5, 1, 5]
朋友 = [5, 1, 4]
```

算出来的点积越大，说明你俩口味越接近。AI 里判断"两段文字像不像""两个词义近不近"，
底层干的都是这件事。

**避坑提醒**

- 两个向量的**长度必须一样**才能算点积，维度不同没法对应相乘
- 结果是**一个数**，不是向量——这是最容易记混的地方
- 别跟"逐元素相乘"搞混：`[1,2,3] × [4,5,6]` 逐元素乘得到 `[4,10,18]`（三个数），
  点积得到 `32`（一个数）

## Phase 2：机器学习基础

### 超参数 vs 参数 — 菜谱与手感

**核心要点**

| | 谁定的 | 什么时候定 | 例子 |
| --- | --- | --- | --- |
| **超参数** | **人** | 训练**开始前** | 树的数量、学习率、批大小 |
| **参数** | **模型自己** | 训练**过程中**学会的 | 分裂阈值、叶子节点的预测值、神经网络权重 |

**趣味类比回顾**

- **超参数 = 你给的菜谱**：开火前就写好了"放几棵树、火开多大"
- **参数 = 厨师练出来的手感**：炒的过程中自己掌握的咸淡、火候

菜谱是你决定的；手感是厨师自己长出来的。这就是两者的分界线。

**避坑提醒**

- 判断口诀：**"要提前调的就是超参数，训练完自动有的就是参数"**
- 随机森林的"树的数量"是超参数（你定的）；"每棵树的分裂阈值"是参数（模型学的）——
  考试和面试最爱考这一对

## Phase 7：Transformer 深入

### LoRA — 贴便利贴式的微调

**核心要点**

微调大语言模型时，LoRA 的做法是：

- **冻结**基础模型的全部原始权重（一个字都不改）
- 只训练一小块新增的**低秩适配矩阵**

结果是**改动成本极低**，但模型能适配新任务。

**趣味类比回顾**

不是把整本书**重新印一遍**，而是在书上**贴几张便利贴**做修改。

书还是那本书（基础模型不动），便利贴很薄很少（低秩适配器），
但翻到对应页面时，读者看到的就是修改后的内容。

**避坑提醒**

- LoRA 让微调**更省资源**（省显存、省时间），**不是**让模型变大
- 最容易选错的反向答案：**"复制模型层来提升适应能力"**——这会让模型翻倍变大，
  跟 LoRA 的目的完全相反
- 记住一个词就够了：**冻结（freeze）**。看见"基础模型权重保持冻结"基本就是它
